How this works

Frameworks change; loops are forever. Every lesson cycles through seven beats — intuition before jargon, mechanism before frameworks, and a quiz so you can't lie to yourself. All code runs offline against a deterministic MockLLM.

MOTTOThe whole lesson in one sentence.
PROBLEMThe concrete pain that makes this topic exist.
CONCEPTAnalogies and ASCII diagrams before any jargon.
BUILD ITThe mechanism, from scratch — code included.
USE ITThe frameworks and APIs, with their tradeoffs.
WAR STORYA real incident, paper, or engineering legend.
CHECKPOINTQuiz questions. Can't answer? Re-read.

About

Frameworks change. Loops are forever.

When you've written the agent loop yourself, every framework becomes readable. When you've built memory, RAG, and handoffs by hand, every architecture diagram is familiar. And when you've attacked your own agent with prompt injection, you'll never ship the naive version again. 20 phases from the bare loop to swarms, open models (Hermes, Llama, Qwen), MCP servers, evals, security, and production — ending in case studies and capstones you actually ship. MIT licensed. No paywalls. Runs on your laptop, offline.
